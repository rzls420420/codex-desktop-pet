# 白龙小姐桌宠：Linux

本包包含当前透明版动作素材，不包含旧素材、原始生成图或账号数据。

需要 Python 3.10+、PyQt5，以及可用的图形桌面。Ubuntu 可按需使用系统包管理器安装 `python3-pyqt5`。本包不是自带 Python 运行时的独立二进制程序。

在解压后的目录运行 `./start.sh` 独立启动；运行 `./follow-codex.sh` 可启动后台监视器，在 Codex 桌面程序启动和退出时启动和关闭桌宠。监视器当前识别 `/usr/lib/chatgpt/ChatGPT`，其他安装路径未适配；不会自动添加开机启动。

左键交互和拖动，右键可选择睡眠、动作预览、额度、开机启动和退出。勾选开机启动后，登录桌面时直接启动宠物，不再随 Codex 退出而关闭；取消勾选会移除该自启动项，跟随模式仍需运行 `./follow-codex.sh`。移动或删除解压目录后需要重新设置开机启动。任务状态依赖本地 Codex 会话记录，远程任务或异常退出可能无法判断。额度查询需要本地 Codex CLI 和可识别的当前账号，不可用时不会编造数据。

任务进行时，气泡会显示最近活跃会话的上下文用量（最近一次请求的输入与输出之和）和缓存输入占该请求输入的比例；右键也可查询。无有效数据时显示不可用，多会话时不一定是当前界面选中的会话。
